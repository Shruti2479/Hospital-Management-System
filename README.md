The Hospital Management System is a modern web-based application designed to manage and streamline hospital operations efficiently. It leverages Supabase as the backend to provide real-time data handling, secure authentication, and scalable database management.

This system enables hospitals to manage patient records, appointments, billing, and staff details in a centralized platform, reducing manual work and improving accuracy.

Key Features:
Patient registration and secure data storage
Doctor and staff management
Appointment scheduling system
Real-time database updates using Supabase
Authentication and user management
Billing and record tracking
Objectives:
Improve operational efficiency in hospitals
Ensure secure and reliable data management
Enable real-time access to patient and hospital data
Reduce paperwork and manual errors
